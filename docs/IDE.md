# GHL Studio

Open `ide/index.html` in a browser for a VS Code–inspired layout:

- Explorer
- Editor with line numbers
- Problems panel
- Integrated terminal panel
- Build / Check actions (client-side simulation)

For real compiles, use the CLI:

```bash
ghlc build
ghlc run
```

Future versions can connect Studio to `ghlc` via a local language server.
